End-to-End System Workflow

How artifacts flow from creation to global rendering in milliseconds.

Step 01 Upload
Upload Artifact
Drag-and-drop .html file on the minimal Web Portal OR send a single POST /api/artifacts with x-auth-token.
Step 02 Process
Token Check & Versioning
Server verifies AUTH_TOKEN. If artifact exists with same ID (UUID-4), increments to v2, v3, etc. Else generates a standard UUID-4.
Step 03 Store
Database & Disk Persistence
Metadata (title, size, version history) stored in MongoDB, raw HTML stored in data/artifacts/:id/:version.html for instant static streaming.
Step 04 Render
Global Public Viewer
Anyone globally opens https://artifacts.domain.com/a/:id. Secure sandboxed iframe loads HTML with version switcher and responsive preview modes.

Core Technical Stack Recommendation

  • Runtime: Node.js (v20+ LTS) using lightweight ES Modules.
  • Web Framework: Express.js or Hono for Node — fast, zero boilerplate, effortless file streaming.
  • Process Daemon: PM2 with automatic restart, log rotation, and systemd boot survival.
  • Network Gateway: Cloudflare Tunnel (or Nginx reverse proxy on Home Server) exposing port 3008 securely to the internet with free SSL.
  • Frontend: Pure Vanilla HTML/CSS/JS (zero build step, instant load, embedded directly in Node static routes).

Selected Strategy: Hybrid Storage Engine

We use your existing MongoDB 7 running on the home server (at mongodb://127.0.0.1:27017/artifacts_db or your Docker container) to store artifact IDs, slug references, version lists, metadata, and timestamps. The raw HTML contents are written to ./data/artifacts/:id/:version.html. If MongoDB is temporarily down, the system can even fall back to disk reads!

Security & Sandboxing Architecture

How to safely render arbitrary user HTML without risking server or host integrity.

1. Timing-Safe Token Authorization

Upload & deletion endpoints verify ARTIFACT_ACCESS_TOKEN using SHA-256 pre-hashed buffers with crypto.timingSafeEqual() to prevent length-oracle and timing attacks.

2. Zero-Trust Opaque Sandbox on /raw

/raw/:uuid/:version sends Content-Security-Policy: sandbox allow-scripts allow-forms allow-popups allow-modals; giving the document an opaque/null origin so it can NEVER access parent cookies or tokens.

3. Strict Path & XSS Sanitization

Strict UUID-4 regex validation and integer version casting. All titles and descriptions are HTML-escaped before injection into viewer templates and OpenGraph tags.

// Hardened Timing-Safe Auth Middleware import crypto from 'crypto'; export const authGuard = (req, res, next) => { const token = req.headers['x-access-token'] || req.headers['authorization']?.replace('Bearer ', ''); const secret = process.env.ARTIFACT_ACCESS_TOKEN; if (!token || !secret) { return res.status(401).json({ error: { code: 'UNAUTHORIZED', message: 'Invalid access token.' } }); } const hashA = crypto.createHash('sha256').update(String(token)).digest(); const hashB = crypto.createHash('sha256').update(String(secret)).digest(); if (!crypto.timingSafeEqual(hashA, hashB)) { return res.status(401).json({ error: { code: 'UNAUTHORIZED', message: 'Invalid access token.' } }); } next(); };

Home Server & PM2 Deployment Blueprint

Simple, rock-solid production setup on your home server.

1. Environment Configuration (.env)

# Server Settings PORT=3008 NODE_ENV=production BASE_URL=https://artifacts.vinitk.com # Security Token for Uploads ARTIFACT_ACCESS_TOKEN=vinitk_art_sec_99482710394817 # Storage & Database MONGO_URI=mongodb://127.0.0.1:27017/artifacts_db STORAGE_PATH=./data/artifacts MAX_FILE_SIZE_MB=25

2. PM2 Ecosystem File (ecosystem.config.js)

module.exports = { apps: [{ name: 'artifacts-service', script: 'src/server.js', instances: 1, autorestart: true, watch: false, max_memory_restart: '500M', env: { NODE_ENV: 'production', PORT: 3008 } }] };

3. Quick 1-Command CLI Uploader Function

Add this to your ~/.zshrc on your Mac or server to upload any HTML file with a single command:

# Add to ~/.zshrc or ~/.bashrc pubart() { local file="$1" local token="$ARTIFACT_ACCESS_TOKEN" curl -s -X POST https://artifacts.vinitk.com/api/artifacts \ -H "Authorization: Bearer $token" \ -F "file=@$file" | jq -r '.url' } # Usage: pubart report.html -> https://artifacts.vinitk.com/a/x8y2q
